## 🌲 Branch Strategy

| Branch          | Purpose                         | Deploys To                            | Backend URL                                    |
| --------------- | ------------------------------- | ------------------------------------- | ---------------------------------------------- |
| **`deploy`**    | Website (Next.js) + its backend | Netlify (website)<br>Render (backend) | `https://verses-backend.onrender.com/api`      |
| **`develop-2`** | Mobile app's backend only       | Render (separate service)             | `https://verses-backend-dev2.onrender.com/api` |

### Why Two Backends?

- Website backend (`deploy` branch) = Production API for the web app
- Mobile backend (`develop-2` branch) = Separate testing/staging API for the React Native app to avoid breaking the website during mobile development

### Build Mobile APK

```bash
cd verses-mobile
npx eas build --profile preview --platform android
# Wait ~10-20 min
# Download APK from link in terminal
```

**⚠️ IMPORTANT:** Always run `eas build` from **inside** `verses-mobile/` directory, NOT from the root! If you accidentally generate `eas.json` in the root, delete it before rebuilding.

### Seed Backend Data

```bash
cd backend

# Create admin user
npm run seed:admin

# Import feelings from frontend JSON
npm run seed:feelings
```

3. Click "Logs" tab

## 🐛 Troubleshooting

### Backend Returns 500 / Data Not Loading

- **Render free tier cold starts:** First request after 15 min inactivity takes 30-60s
- Check Render logs for errors
- Verify MongoDB connection string is correct
- Mobile app has a `wakeUpBackend()` ping on app launch to mitigate cold starts

### Mobile Build Fails

- Run `npx eas build` from **inside** `verses-mobile/` directory
- Delete any `eas.json` in the root directory
- Check `app.json` plugins array (don't add packages that aren't config plugins)

### CORS Errors

- Check `CORS_ORIGIN` in Render environment variables matches your frontend URL
- Mobile apps don't need strict CORS (can use `*`)

### Tab Bar Hidden Behind Android Nav Buttons

- Fixed with `useSafeAreaInsets()` in `DynamicIslandTabBar.tsx`
- `edgeToEdgeEnabled: true` in `app.json` requires safe area handling

### Haptics Not Working

- `expo-haptics` doesn't go in plugins array (not a config plugin)
- Fallback to `Vibration` API is in `lib/haptics.ts`
- Requires `VIBRATE` permission in `app.json`

## 📌 Final Tips

1. **Always check which branch you're on** before making changes
2. **Test locally first** (especially backend changes) before pushing
3. **Render free tier** = cold starts. Upgrade to paid ($7/mo) for instant loads.
4. **Mobile APK builds** take 10-20 minutes. Be patient.
5. **Favorites badge updates in real-time** via listener system in `lib/favorites.ts`
6. **All animations** are `react-native-reanimated` entering/exiting animations (no custom Animated API)
7. **Backend seeding** is manual. Run `npm run seed:feelings` after cloning or resetting DB.
